# المقدمة

في عصر التكنولوجيا الحديثة، أصبح الذكاء الاصطناعي (AI) جزءًا لا يتجزأ من حياتنا اليومية. من المساعدات الصوتية مثل Siri وGoogle Assistant إلى أنظمة الترجمة الآلية والروبوتات، يقدم الذكاء الاصطناعي حلولًا مبتكرة لتحسين كفاءة الأعمال وتسهيل حياة الأفراد. في هذا المقال، سنتعرف على كيفية بناء مساعد ذكاء اصطناعي باستخدام **DeepSeek**، وهي منصة قوية تعتمد على نماذج لغوية كبيرة (LLMs) لتوفير إجابات دقيقة ومفيدة.

---

## ما هو DeepSeek؟

**DeepSeek** هو نظام ذكاء اصطناعي متقدم يعتمد على نماذج لغوية كبيرة (Large Language Models - LLMs). يتميز DeepSeek بقدرته على فهم النصوص المعقدة وتوليدها بشكل طبيعي، مما يجعله خيارًا مثاليًا لبناء مساعدين ذكاء اصطناعي. يمكن استخدام DeepSeek لتطوير بوتات الدردشة، المساعدات الشخصية، وأدوات الدعم الفني.

---

## أهداف المشروع

- بناء مساعد ذكاء اصطناعي قادر على الرد على استفسارات المستخدمين.
- دمج **DeepSeek** مع واجهة مستخدم أو قناة اتصال (مثل واتساب أو موقع ويب).
- تحسين التجربة العامة للمستخدمين من خلال تقديم ردود دقيقة وسريعة.

### المرحلة 3: كتابة الكود

#### الخطوة 3.1: إنشاء ملف Python للتفاعل مع DeepSeek
قم بإنشاء ملف باسم deepseek_assistant.py وإضافة الكود التالي:
   ```bash
   import requests
from flask import Flask, request, jsonify

# إعدادات DeepSeek API
API_URL = "http://localhost:8000/api/v1/generate"
API_KEY = "YOUR_DEEPSEEK_API_KEY"   # ده api key الي هيجي من موقع ديب سيك لزم يتغير

app = Flask(__name__)

def ask_deepseek(prompt):
    headers = {
        "Authorization": f"Bearer {API_KEY}"
    }
    data = {
        "prompt": prompt,
        "max_tokens": 100
    }
    response = requests.post(API_URL, headers=headers, json=data)
    return response.json().get("response", "عذراً، لم أتمكن من فهم سؤالك.")

@app.route('/ask', methods=['POST'])
def handle_request():
    user_message = request.json.get('message', '')
    if not user_message:
        return jsonify({"error": "لا يوجد نص في الرسالة."}), 400
    assistant_response = ask_deepseek(user_message)
    return jsonify({"response": assistant_response})

if __name__ == '__main__':
    app.run(debug=True, port=5000)
   ```

## شرح الكود:

- **طلب بيانات من DeepSeek**: يتم إرسال النص الوارد (**prompt**) إلى **DeepSeek** عبر طلب **POST**.
- **إنشاء واجهة خدمة (API)**: تم استخدام **Flask** لإنشاء نقطة نهاية `/ask` تتلقى الرسائل الواردة وترسلها إلى **DeepSeek**.
- **إرجاع الردود**: يتم إرسال الردود إلى المستخدم في شكل **JSON**.

## المرحلة 4: اختبار المساعد الذكي

### الخطوة 4.1: تشغيل التطبيق
- قم بتشغيل التطبيق باستخدام الأمر التالي:
   ```bash
   python deepseek_assistant.py 
   ```
- سيتم تشغيل التطبيق على العنوان التالي: `http://localhost:5000`.

### الخطوة 4.2: إجراء اختبار باستخدام **Postman** أو **cURL**
- قم بإرسال طلب **POST** إلى `http://localhost:5000/ask` مع بيانات **JSON** كالتالي:

  ```json
   {
  "message": "ما هي عاصمة فرنسا؟"
   } 
   ```
   -  ستتلقى ردًا مشابهًا لهذا:

   ```json
   {
  "response": "عاصمة فرنسا هي باريس."
   }
   ```


## المرحلة 5: دمج المساعد مع واتساب أو موقع ويب

### الخطوة 5.1: دمج المساعد مع واتساب Business

   - إرسال الرسائل الواردة إلى نقطة النهاية الخاصة بك `http://your-server-address/ask`.
   - إرجاع الردود إلى واتساب.

### الخطوة 5.2: دمج المساعد مع موقع ويب
